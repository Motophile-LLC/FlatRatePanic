# Hard R Cycles: Flat Rate Panic — Game Specification & Architectural Guardrails

## Overview
**Hard R Cycles: Flat Rate Panic** is a fast-paced, comedic 2.5D arcade motorcycle workshop game built with Next.js (App Router), React Three Fiber, `@react-three/drei`, `@react-three/rapier`, Zustand, Web Audio, and Supabase.

## Architectural Guardrails

### 1. SSR Protection
- All React Three Fiber `<Canvas>` components and Three.js / Rapier imports MUST remain isolated inside client-only modules loaded dynamically via `next/dynamic(..., { ssr: false })` (see `src/components/canvas/GameCanvasWrapper.tsx`).

### 2. 60FPS State & Loop Discipline
- Zero React `useState` updates inside R3F `useFrame` loops or `requestAnimationFrame` mini-game loops.
- High-frequency state (`bayTimer`, `torqueNeedle`, `chaosMeter`, `cameraShake`, `particleBursts`) lives in `src/store/useGameStore.ts` and is read/mutated via `useGameStore.getState()` and refs.
- React components subscribe narrowly to discrete UI slices (`phase`, `activeHazard`, `currentJobIndex`, `equippedTool`, etc.).

### 3. Billboard Sprite Rendering & Depth Sorting
- All 2D character `<Billboard>` materials MUST enforce `alphaTest={0.5}`, `depthWrite={true}`, and crisp texture settings (`THREE.SRGBColorSpace`, `anisotropy = 16`).
- Never rely solely on `transparent={true}` without `alphaTest`, which causes z-fighting and background props bleeding through character outlines.

### 4. Texture Preloading & Procedural Fallbacks
- Character poses are loaded from `/public/sprites/manifest.json` generated by `scripts/slice-sprites.mjs`.
- `src/utils/proceduralSprites.ts` provides immediate Canvas2D cartoon fallback textures for any missing character pose so gameplay always remains testable.

### 5. TypeScript, Accessibility & API Security
- Strict TypeScript across store state, hazards, tools, and API payloads.
- Modal overlays use native `<dialog>` elements opened via `showModal()`, styled with `overscroll-behavior: contain` on `dialog:modal` and `overflow: hidden; overscroll-behavior: contain;` on `dialog::backdrop`.
- Scoreboard writes validate bounds in `/src/app/api/repair-orders/route.ts` and enforce matching Postgres `CHECK` constraints + Row Level Security (RLS) policies in `supabase/migrations/01_repair_orders_rls.sql`.
